# خدمة التفسير — API ثابت

خدمة استعلام فورية لـ**41 طبعة تفسير عربية**. أرسل طلب HTTP واحد واستقبل كل ما تحتاج — بلا تحميل ولا مفاتيح ولا حدود.

## نقطتا الاستعلام

```
١) آية واحدة من كل الطبعات:   GET /api/ayah/<سورة>/<آية>.json.gz
٢) سورة كاملة من طبعة واحدة:  GET /api/ed/<slug>/s<NNN>.json.gz
```

مثال — آية الكرسي من الـ41 تفسيراً دفعة واحدة:

```bash
curl -s https://medmrf-10.github.io/tfsr/api/ayah/2/255.json.gz | gunzip
```

الرد:

```json
{"s":2,"a":255,"tafsir":{
  "ar-tafsir-ibn-kathir": {"g":"2:255","f":"2:255","t":"2:255","p":"<نص التفسير صافياً>","x":"<HTML الأصلي>"},
  "... (41 طبعة)": {}
}}
```

**الحقول**: `g` مفتاح المقطع المجمَّع · `f`/`t` من آية إلى آية · **`p` النص الصافي — استخدمه** · `x` HTML الطبعة خاماً.
من لا تفسره الطبعة (أو سورة خارجها) يغيب عن الرد — غياب slug = لا تغطية.

`ed/<slug>/s<NNN>` = كل آيات السورة من طبعة واحدة برد واحد — لتجميع طبعة دون ضرب عدد الطبعات في حجم الرد. الأكواد: `GET /api/index.json` ← `editions`. ميتا الطبعة: `GET /api/editions/<slug>.json.gz`.

## قاعدة البيانات الكاملة

`releases/` — `tafsir.db.gz` (SQLite، 610MB): نفس البيانات بفهارس FTS5 مُجرّدة الحركات/الألف/الياء + مرافق `query.py`.

## ملاحظة الضغط

كل الملفات `.json.gz` — فك الضغط: `curl -s <url> | gunzip` أو بايثون `gzip.open`.
